# Установка окружения `clean_env`

Процедура воспроизводит окружение пайплайна предсказания EC-номеров на новой машине
(ноутбук или кластер). Только `venv` + `pip`, без conda/poetry/docker.

## Требования к интерпретатору

Нужен **Python 3.10** (допустимо 3.9). Это потолок: `numpy 1.22.3` и `pandas 1.4.2`
не имеют колёс под Python 3.11 и выше и не собираются из исходников на новых
интерпретаторах. Проверить, что нужный Python есть:

```bash
python3.10 --version    # ожидается Python 3.10.x
```

Если на кластере используется система модулей — сначала подгрузить нужную версию,
например `module load python/3.10` (точное имя модуля уточнить через `module avail python`).

---

## Установка

```bash
python3.10 -m venv clean_env
source clean_env/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

---

## Внешние зависимости вне pip

Ставятся отдельно, в `requirements.txt` их нет:

- **MMseqs2** — внешний CLI для стратификации по гомологии. Нужна сборка под
  набор инструкций compute-узла: на узлах без AVX2 бинарь AVX2 падает с `rc=-4`
  (SIGILL). Использовать **статическую SSE4.1-сборку**; путь к бинарю задаётся
  переменной окружения `MMSEQS_BIN` (`export MMSEQS_BIN=/путь/к/mmseqs`, см. README).
- **TensorFlow** — *не обязателен*. Нужен только для быстрого чтения TFRecord
  ProteInfer. При его отсутствии `7_EVALUATION.py` переключается на встроенный
  ручной разбор protobuf, поэтому в базовое окружение TF не добавлен (он тяжёлый).
  При желании ставится отдельно, совместимой с Python 3.10 версией.

## Проверка окружения

После установки:

```bash
python - <<'PY'
import numpy, pandas, pyarrow, matplotlib, sklearn, scipy
for m in (numpy, pandas, pyarrow, matplotlib, sklearn, scipy):
    print(f"{m.__name__:12s} {m.__version__}")
PY
```

Ожидаемый вывод (транзитивные версии могут слегка отличаться, ключевые — фиксированы):

```
numpy        1.22.3
pandas       1.4.2
pyarrow      20.0.0
matplotlib   3.7.0
sklearn      1.2.0
scipy        1.11.4
```

## Замечание по версиям

В тексте ВКР (раздел 2.1, этап ODB) для предобработки указаны `pandas 1.3.5` и
`numpy 1.21.5` — версии на раннем этапе работы. Итоговое консолидированное
окружение `clean_env` использует `pandas 1.4.2` / `numpy 1.22.3`; на результатах
этапа ODB (`explode`, `dropna`, `drop_duplicates`) разница между этими минорными
версиями не сказывается. Данная процедура собрана под `clean_env`.
